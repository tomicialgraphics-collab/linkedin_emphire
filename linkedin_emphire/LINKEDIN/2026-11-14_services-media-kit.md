# Services page media: three items, in order

Three files are in the Drive folder `2026-11-14 services media`. Each one goes into a different slot for a different reason: the first shows work, the second shows the cheapest way to buy, the third makes the claim in one glance.

## 1. Playbook card, link to GitHub

**Link:** https://github.com/Teamthy/Ai-Red-Team-Playbook
**Image:** `01 playbook-card 1280x640.png`, 1280 by 640, Drive id `10NOs4OIvcflk-esabsHmPPGy_VaA8WKG`
**Title:** "AI Red Team Playbook: 168 testable classes"
**Description:** "Six categories, MIT code, CC BY text, and the tooling to turn a run into a coverage argument someone else can check."

This is the only item that shows work rather than describing it, which is why it goes first. The repository is public and MIT, so the click lands somewhere that keeps the promise the card makes.

## 3. The 16 of 64 card, no link

## A note on the set

The first and third are near-black terminal cards and the second is a bright cyan treatment with stock imagery. Side by side the second reads as advertising and the other two read as evidence. That is not fatal, because the second one has to match the Upwork listing where the image already appears, and matching the listing matters more than matching the other two.

If the set is ever rebuilt, make the scan card in the same terminal style with the price as the hero, and the set stops looking like it came from two people.

## After adding

Check the order on the profile. LinkedIn shows media in the order added, and the first three thumbnails are what a visitor sees without scrolling. Playbook first, scan second, evidence third.
