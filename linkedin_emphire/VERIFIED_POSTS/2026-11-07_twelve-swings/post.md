Tesla's plan puts a full design-make-test loop on a thirty-day clock at Giga Texas. Twelve swings at a new silicon bet a year, where the industry gets one. The interesting number is not twelve. It is how many of the twelve you can attribute.

A loop that fast only compounds if each cycle changes one thing and the result says which change did it. Move the process, the materials, the design and the schedule together and you get twelve samples of everything, which is the same as one sample twelve times. Volume without attribution is motion.

AI teams have the same failure mode and it is quieter, because the cycles are shorter. A prompt change, a model upgrade, a retrieval tweak and a new judge all ship in the same week, the score improves, and nobody can say which one did it. The next regression then starts as an archaeology project.

Attribution is bookkeeping before it is science:

→ One change per cycle, written down before the run.

→ The baseline recorded at the moment of the change, not reconstructed from memory afterwards.

→ Every run tagged with the version of the thing that tested it, not just the thing that was tested.

→ Failures kept in the same table as the wins, because the next cycle inherits both.

Twelve swings a year is a research programme for the team that can say what each swing taught it. For everyone else it is twelve invoices.

Faster is not the advantage. Attributable is.
