# The first comment spine

Standing arrangement from 9 November, recorded as R31 in the rule registry and rendered into PIPELINE/20-RULES.md. Every
post carries the AI Red Team Playbook link in its first comment until the repository reaches 1,000 stars. The count itself
never appears in public.

## Four lines, only the first one changes

Line one names the file in the repository that answers the specific post, with the number attached. If the post is about
rates and samples, that file is wilson.py. If the post is about coverage, it is the checklist data file. If the post is
about an agent going off script, it is the example engagement and its transcript.

Line two is constant. It is public and free, CC BY for the writing and MIT for the code, plus the address.

Line three is constant. A star costs nothing, and it is how the next person testing an AI product finds this before
rebuilding it.

Line four is optional and only appears when the post invites disagreement: argue with it if a class is missing.

## Why a spine and not a slogan

A bare link gets scrolled past because it gives the reader nothing to do. A link that names the file solving the problem the
post just described gets clicked, and the star follows the click. That is the whole mechanic, and it is why the first line
has to be rewritten for every post rather than templated.

## Two comments are already written

The span scoring post at 13:30 WAT uses `ENGAGEMENT/2026-11-09_comment_span-scoring-playbook-link.md`. The launch post at

## What breaks this

Quoting the star count. It is small now and the sentence gets worse every week it stays small. Asking for a favour instead
of offering a tool. And putting the link in the post body, which costs reach and is only correct for the launch post itself.
