# Agreed, as the owner reports it

1. Marvin pays for the Claude subscription.
2. A Nigerian company is registered. Owner 51 per cent, Marvin 49.
3. Hosting runs on Marvin's server until there is revenue.
4. The first money in goes to the server and the hosting before it goes to either of them.
5. No deadline. The owner has time and no other paying work.

# The five things that will matter more than the split

**What the 49 per cent is for.** Right now it buys review time, a server and a subscription. In month nine it may buy
a phone call a week. If one of them stops working on it, the other needs to know what happens to the shares without
having a fight about it. A short written answer now is worth more than a fair one later.

**Who owns the code and the name.** The code will be written by the owner on a subscription Marvin pays for. That is
two claims on the same object, and it is the most common place for a small partnership to come apart.

**When the hosting debt ends.** "First money goes to the server" needs an end condition, a figure or a number of
months, or the first customer's payment disappears into infrastructure with nobody able to say when it stopped.

**How Marvin holds 49 per cent.** Personally, or through a company. This changes what the Nigerian filing looks like,
so it is worth knowing before the name search rather than after.

**Whether the split fits the grant.** The iDICE route needs a signed partner and a working product. Whether a 51/49
split with a foreign co-founder affects eligibility is a question for them, asked before the application is written,
not after.

# Order

1. Ask Marvin the five questions in one message, and ask for answers in writing.
2. Find out what registration actually costs and requires. Do not estimate it in conversation until it has been looked
   up once.
3. Only then write anything that looks like an agreement, so that whatever a lawyer or an agent eventually sees is a
   document, not a transcript.

# What changes in the writing to Marvin, from now on

He is a co-builder, so the message changes shape. No thanking him for his document. Disagree flatly and give the
reason. Say what I am doing this week and what I need from him, in that order. Keep the three-line daily note and the
Friday call, because rhythm is the only thing that survives when there is no deadline.
