# Card assets

`avatar.jpg` goes here: a square crop of his face, at least 200 px, which the identity chip on every
card uses. Until it exists the chip draws an "OT" monogram disc instead, which is a placeholder and reads
like one.

Nothing else belongs in this folder. The card is type, rule and one yellow block; adding an illustration
here would be the one element on the card saying nothing true.
