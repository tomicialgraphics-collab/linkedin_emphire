On the refusal, one suggestion before you name it. A 400 with an error string and a message is a response, and it isn't an instrument until something can fail against it. The shape I'd want is a pair: the same request body sent twice, identical in every field except a non-zero segment range on one of them, asserting the status and the exact body on both. If the two differ only in the segment field, the refusal is being tested. If anything else differs, the refusal is being demonstrated. Get that pair working and the finding code has something to point at, and the vector has something to break.

Wherever the extent lands, write down what it covers. A per-batch anchor answers that a batch existed. It doesn't answer that a stream is continuous, and that gap is the one this register has been circling since v0.6. One transaction for one batch is a real extent and a narrower claim, and the narrower claim is the one that survives being read by somebody who didn't build it.
