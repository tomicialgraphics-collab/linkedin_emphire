# Rules for any follow list produced here

Set by the owner on 6 November 2026, after two rounds of a list that gave search links where he wanted
profile links.

1. Every name in a follow list is a clickable link. No exceptions and no plain text names.
2. The address is printed under the name as well as linked, so it can be copied on a phone or pasted into
   a message without opening the page first.
3. A direct profile address is used only where something outside LinkedIn ties the slug to the person: this
   project's own record of a profile read, the person's own site, their own GitHub, or a search result whose
   company and article titles match the follower list. The evidence for each one is stated in the file.
4. Where no such evidence exists, the link opens a LinkedIn people search carrying the name and the employer,
   and the row says so. A guessed slug is worse than a search, because a connection request sent to a
   stranger cannot be recalled.
5. LinkedIn refuses this environment with HTTP 403, so no profile can be opened here to confirm it by eye.
   That limit is stated in every list rather than hidden behind a link that looks authoritative.
6. If the owner pastes a profile address, it is pinned into the list and the search link for that person is
   removed. That is the fastest route to a fully direct list, and it costs him one copy per person.
