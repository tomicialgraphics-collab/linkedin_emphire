## Recommended pair

**HEADLINE:** Your merge rate is measuring your reviewers.

**SUBHEADLINE:** GitHub says 40 percent of pull requests now start with an agent. That number has a denominator nobody publishes.

168 characters together, complete before the cut. The headline is the memorable line, the subheadline carries the number and adds the thing the headline does not say.

**First line of the post:** the subheadline, verbatim. It is 112 characters, a number fighting its own unit, and it cannot be resolved without line two.

## Alternatives

**A**

HEADLINE: The agent wrote the code. A person opened the pull request.

SUBHEADLINE: So the 40 percent everyone is quoting counts survivors, not attempts.

**B**

Recommended is the first pair. It names the reader's own dashboard in the headline, which is the only version where the reader feels the problem is theirs within three words.
